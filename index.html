NESCAFÉ Page Request

Request a page update in 3 steps

  1. Paste the URL of the NESCAFÉ page and click Load.
  2. With Edit mode on, click any text, image or button and choose: Replace text, Replace image or Add comment. Changed elements get a green frame.
  3. Fill in the request details on the right and click Prepare request — you get an annotated screenshot and a ready-to-paste description.
Tip: switch Edit mode off to click through links and open another page.
